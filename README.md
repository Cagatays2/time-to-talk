# Time to Talk

Time to Talk is a React, TypeScript, and Tailwind CSS communication app for building clear spoken sentences with large touch-friendly buttons.

The published version is frontend-only. It does not include an API server, AI calls, or any secret keys.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

This repo includes a GitHub Actions workflow for GitHub Pages. In GitHub, set:

- Settings -> Pages -> Source: GitHub Actions

Then push to `main`.
